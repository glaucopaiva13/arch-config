# Arch Linux Config

Este repositório contém minha configuração pessoal visando customização.

## Estrutura

- `hypr/`
  - `hyprland.conf` — configuração do Hyprland.
  - `hyprpaper.conf` — configuração do Hyprpaper para o papel de parede.
- `kitty/`
  - `kitty.conf` — configuração principal do terminal Kitty.
  - `kitty.conf.bak` — backup de configuração.
- `nvim/`
  - `init.lua` — arquivo de inicialização do Neovim.
  - `lua/plugins/` — configurações dos plugins instalados.
- `starship/`
  - `starship.toml` — tema e prompts do Starship.
- `waybar/`
  - `config.jsonc` — configuração do Waybar.
  - `macchiato.css` — tema CSS do Waybar.
  - `style.css` — estilos adicionais.
- `wofi/`
  - `config` — configuração do Wofi.
  - `style.css` — estilos do Wofi.

## Notas

- Alguns plugins do neovim pode estar desatualizados.
